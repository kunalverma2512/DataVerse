# Emotion Detection from Hindi Speech

An advanced machine learning pipeline that identifies human emotion (Angry, Happy, Neutral, Sad) from raw Hindi speech audio. This repository implements a high-performance **Transfer Learning** architecture, bypassing traditional audio spectrogram processing in favor of pre-trained foundation models.

## 🌟 Peak Accuracy: 76.68% (Kaggle Leaderboard)

## Architecture Overview
This unified framework utilizes a two-stage process:
1.  **Deep Feature Extraction:** Raw audio (16kHz, mono, padded to 30s) is passed through OpenAI's frozen `Whisper-Base` encoder to extract rich, 512-Dimensional semantic and acoustic embeddings.
2.  **Soft-Voting Mega Ensemble:** The extracted embeddings are classified using a mathematically robust ensemble combining Class-Balanced Logistic Regression, an RBF-Kernel Support Vector Machine (SVM), and XGBoost. Final predictions are generated by averaging the probability distributions (Soft-Voting).

## Getting Started

### 1. Installation
Install the required deep learning and machine learning libraries:
```bash
pip install -r requirements.txt
```

### 2. Data Preparation
Place the raw audio files in `data/raw/train/` and `data/raw/test/`. Ensure `train.csv` and `test.csv` are in `data/raw/`.

### 3. Feature Extraction
Run the Whisper encoder to convert the raw audio into mathematical embeddings.
```bash
python src/data/extract_embeddings.py
```
*This will generate `whisper_train.csv` and `whisper_test.csv` in the `data/processed/` directory.*

### 4. Model Training & Inference
Train the Machine Learning ensemble and generate the final predictions.
```bash
python src/models/train_ensemble.py
```
*This will output the final predictions to `outputs/submissions/submission_whisper_ensemble.csv`.*
